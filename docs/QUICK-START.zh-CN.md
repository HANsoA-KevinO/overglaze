## 安装与使用

1. **安装应用。** 运行 Setup，选择本地可写目录。使用便携版时，完整解压 ZIP，打开根目录的 Open-Overglaze.cmd；两种方式任选一种。
2. **导入模型。** 在「模型配置」中点「导入模型」，选择自己的 nvngx_dlssnr.dll。跳过配置后，可从「设置」→「配置模型」重新进入。显示「模型已识别」后进入游戏库。要换模型（例如在 310.8.0.0 和 310.9.16.0 之间切换），在「模型配置」中点「重新选择」，选另一个文件即可：原来的模型会保存在釉光的模型库中，随时可以重新导入；已装游戏在游戏库点「更新插件」后才会用上新模型。
3. **添加游戏。** 点「添加游戏」，输入游戏目录或 EXE 路径，再点「检查路径」。选择游戏本体程序，完成添加。
4. **安装插件。** 先退出游戏。选中游戏，点「生成适配包」，再点「安装插件」。弹窗会列出检查发现的保护（反作弊、Denuvo）和风险说明；核对后点「安装」，即表示接受风险。
5. **开启 NR。** 正常启动游戏，在画质设置中开启 DLSS 光线重构、超分辨率或 DLAA。按面板快捷键（默认 Insert）打开面板，开启 NR；Tone、Structure、Style 和输入曝光可在面板中调整。NR 每次启动默认关闭。

面板快捷键默认是 Insert，可以在「设置」→「面板快捷键」或游戏内面板的「高级与诊断」→「面板设置」里修改：点「修改」后按下新的键（一个键，可加 Ctrl / Shift / Alt），「恢复默认（Insert）」改回去。所有游戏和 Steam 启动器共用这一个设置，游戏运行中修改也会立即生效。Esc、Enter、空格、Tab、方向键等面板自己要用的键，以及不带 Ctrl 或 Alt 的字母和数字不能用，界面会说明原因。

添加路径只登记和检查游戏。安装成功也不等于已经运行 NR，实际状态以游戏内面板为准。

## 使用条件

- RTX 50 系显卡及兼容驱动；项目声明的驱动下限为 615。
- 64 位 Windows；已测试系统为 Windows 11。
- 使用 DX12 和 DLSS 的游戏，最适合离线单人游戏。联网或带反作弊的游戏可以安装，风险自负：可能无法启动、被踢出或被处罚（包括封号）；Overglaze 不绕过任何保护。
- 安装游戏插件时，釉光数据所在的盘需有 1 GiB 可用空间。

不支持的游戏或未通过检查的版本，按界面提示处理。不要手动复制插件 DLL 来跳过安装检查。

## 更新与卸载

- **应用更新：** 有新版本时，窗口顶部会出现提示，点「更新」即可（只限用 Setup 安装的副本；便携版只提示并给出下载页）。也可以退出应用，手动运行新 Setup，保留原安装目录。模型、设置和采集资料保留。
- **插件更新：** 退出对应游戏，在游戏库点「更新插件」。
- **游戏更新：** 如提示需要适配，在游戏库点「重新适配」。
- **卸载应用：** 先逐个卸载游戏插件，再删除指向 Overglaze 的外部启动选项，最后卸载应用。用户资料会保留。

## 晚加载游戏

EXE 带 Denuvo 反篡改的游戏（如生化危机 安魂曲），游戏库生成适配包时自动用晚加载：游戏根目录不放文件，安装方式与其他游戏相同。

安装完成后，游戏库显示要填的 Steam 启动选项和「复制」按钮，之后在该游戏的「启动方式」里也能再次复制。格式如下：

    "<Overglaze 根目录>\app\overglaze_launch.exe" %command%

在 Steam 中：库 → 右键游戏 → 属性 → 通用 → 启动选项，粘贴这一行。进入游戏后，首次按面板快捷键（默认 Insert）加载插件并打开面板。卸载 Overglaze 前必须删除这个启动选项，否则游戏无法启动。

不经 Steam 启动的晚加载游戏，游戏库显示的是 `overglaze_games watch` 命令：先运行它并保持窗口打开，再启动游戏。其他用法见 [添加游戏说明](ADDING-A-GAME.md)。

## 反馈

反馈时注明应用版本、游戏版本、显卡、驱动和面板状态，并附必要的错误信息。分享日志前去除个人路径；不要上传模型或游戏 DLL。
