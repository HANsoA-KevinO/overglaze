# 釉光 · Overglaze 0.2.0-preview.16

- **《影之刃零》Steam 版**　在游戏库选择 `steam\PBZ.exe` 时，釉光会找到真正运行游戏画面的 `platform\steam\PBZ.exe`。插件装在启动器下时，进游戏按 Insert 不会弹出面板。
- **旧适配包占名**　如果旧包已经占用了默认名称，为另一条游戏路径生成适配包时，釉光会自动换一个可用名称。旧适配包和安装记录会保留。

升级后，如果插件此前装到了启动器，先退出游戏，在游戏库的旧条目点「卸载插件」，再「从列表移除」。重新添加《影之刃零》，确认路径是 `platform\steam\PBZ.exe`，生成适配包并安装插件。已经装到本体且出现「游戏已变更」提示的玩家，可以直接对原条目点「重新适配」。

安装包和便携包均不附带 NVIDIA NR 模型。
