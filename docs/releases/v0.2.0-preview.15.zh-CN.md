# 釉光 · Overglaze 0.2.0-preview.15 更新公告

- **修复 NR 运行中因锁竞争停止。** Reset、Close、Execute 的关键记录现在按顺序处理，短暂的锁竞争不会丢掉这些记录。GPU 完成信号遇到忙锁会保留并重试。已经提交的工作仍等 GPU 实际完成，再回收资源。这项修复走共用运行时。
- **修复 2077 重新适配报模型冲突。** 游戏库现在检查实际写入位置，游戏根目录的旧模型不会挡住子目录安装。釉光自己安装的文件按身份备份并更新。实际写入位置若有一份身份不同、未由釉光管理的模型，会在卸载前提示。2077 已通过安装预演，并确认重新安装后宿主能加载。另有玩家反馈 2077 运行时连续跳帧并报 `metadata-invalid`，仍在排查。
- **PBZ 实测。** 《影之刃零》经过过场、菜单和读档切换后，NR 仍正常运行。最终记录 4,004 次执行、4,003 次完成、1 次在途，期间没有新增跳帧或错误。这是一次短时功能检查。

Preview 14 的 PBZ 免切 DLSS 档位、游戏本体识别和 Steam 启动器改动，以及 Preview 12 的通用面板与《鬼武者》修复继续保留。

**更新方法**　升级桌面程序后，退出受影响的游戏，在游戏库点「更新插件」。如果上次已经卸载旧插件，点「安装插件」。安装包不附带 NVIDIA NR 模型。
