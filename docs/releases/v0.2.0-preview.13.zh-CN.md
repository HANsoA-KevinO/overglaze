# 釉光 · Overglaze 0.2.0-preview.13 更新公告

本次更新集中修复游戏本体识别、Steam 启动器接入，以及《影之刃零》（PBZ）每次进游戏后需要切换 DLSS 档位才能开启 NR 的问题。此前 Preview 12 的通用面板绘制、帧生成面板闪烁及《鬼武者》绑定保护修复继续保留。

## PBZ：正常进场景后直接开启 NR

已验证的 PBZ 构建改为随游戏启动加载，让釉光及时记录游戏实际创建的 DLSS 实例信息。以后正常进场景，按 Insert 打开面板并开启 NR 即可，不需要每次切换 DLSS 档位，也不需要旧的釉光 Steam 启动项。NR 每次启动仍默认关闭。

这项加载选择同时校验游戏 EXE 和三个图形模块的身份，只覆盖本次通过验证的构建。其他游戏及未验证版本保留原有加载方式，不根据游戏名称或 Denuvo 标签推断兼容性。原有安装身份、DLSS 创建参数和帧准入检查均保留。

已生成的旧晚加载适配包会在游戏库中提示配置更新；「更新插件」会应用新策略。若根目录有其他工具的 dxgi.dll，会在卸载当前插件之前拒绝更新并说明冲突，不覆盖其他工具。

## 通用修复

- **选对游戏本体。** 游戏库识别 7-Zip／8-Zip 独立工具，包括 8za_v2.exe 等数字版本后缀，以及 CheckEnv.exe，避免把它们当成游戏安装。普通游戏名仅仅与工具共享前缀，不会被误判。此前错装的条目仍可按文件身份卸载。
- **Steam 启动器和本体分离也能接入。** 晚加载启动项增加已登记的游戏 ID，保留 Steam 原始启动命令和参数，同时按所选条目的真实 EXE 与安装身份接入。启动器与本体同名、位于不同目录时，不再因只认首个进程而旁路。无效或不存在的 ID 不会回退到其他游戏。

这些属于共用的游戏库和启动器修复；PBZ 的普通加载选择则只对已经验证的构建生效。

## PBZ 实测结果与范围

测试环境：RTX 5090，驱动 621.01。

- 两次独立新进程均未改变 DLSS 档位、帧生成或分辨率，直接开启 NR 成功。
- 第一轮 422 次 NR 执行、422 次 GPU 完成；重启后第二轮 322 次执行、321 次完成，读取时有 1 次仍在处理。两轮均零准入跳过、零执行错误。
- 两个快照各记录了两次历史中断及一次初始化资源重建，不把它们描述成全程零中断。
- 测试者反馈 NR 与 FG 同开暂时正常。

以上是短时功能验证。画质、性能、长时间运行、其他场景及其他游戏的 NR＋FG 兼容性尚未完成系统验收。

## 怎么更新

1. 升级釉光桌面程序。Setup 用户可使用应用内更新；便携用户下载新版 ZIP。
2. 退出受影响的游戏，在游戏库点「更新插件」；尚未安装但已有旧包的，点「刷新适配包」再安装。
3. **PBZ 的已验证构建：** 更新后移除 Steam 属性里旧的釉光启动项，然后正常启动。当前已使用普通加载并通过实测的安装保持原策略。
4. **其他仍需晚加载的游戏：** 从游戏库重新复制包含 --game-id 的完整 Steam 启动项。
5. 若旧条目选中了 8za_v2／CheckEnv 等工具，先卸载错装插件并移除条目，再选择真正的游戏 EXE；PBZ 本体是 platform\steam\PBZ.exe。

本项目不附带、不再分发 NVIDIA NR 模型，模型属于 NVIDIA，由用户自行提供。釉光是实验性的第三方工具，与 NVIDIA 及游戏开发商、发行商没有关联或背书。
