# 釉光 · Overglaze 0.2.0 Preview 12 更新公告

这次集中处理「插件已经启动，游戏里却看不见面板」这一类问题，重点是开启帧生成后面板时有时无、回到游戏前台就闪烁的情况。《鬼武者》当前场景已确认修复；核心改动进入了共用的 DX12 晚加载面板链路，供采用同一路径的游戏使用。

本版包含 Preview 11 之后全部 5 个修复提交，也保留此前开发阶段已合入主线的全部功能。下面先说明本次新增修复，再集中回顾此前版本的功能，方便从旧版直接升级的用户了解完整变化。

## 本次新增：通用面板修复

- **调整面板的绘制时机和提交顺序。** 旧路径在准备显示画面时判断能否安全绘制；遇到复杂的多队列同步，可能频繁跳过面板，表现为闪烁或一直看不见。现在在确认游戏实际提交当前画面后，在同一 GPU 队列紧接着绘制面板，再进入后续同步。游戏原来的提交边界保留，也不会等待所有 GPU 队列排空或修改游戏的帧生成选项。
- **临时缺少条件后可以恢复。** 无关队列的等待不再反复耗尽面板的恢复次数；出现符合条件的新画面提交时可继续绘制。真实的队列变化和冲突仍会重新检查。
- **背景与焦点行为修正。** 面板背景改为不透明；鼠标移出面板仍保持打开。切到另一个显示器或应用时，面板保留打开状态并释放输入，回到游戏后恢复操作。
- **诊断信息更清楚。** 分开记录面板提交、GPU 完成和跳过原因，便于判断究竟是没有加载、没有绘制，还是已经提交但没有出现在最终画面。

这项修复依据游戏实际的渲染提交工作，没有按《鬼武者》的进程名设置专用放行。采用同一晚加载路径、遇到同类问题的游戏可以受益；不同渲染路径或插件未加载、快捷键、其他工具冲突等原因，需要分别检查。跨游戏效果仍需实测。

## 《鬼武者》：适配修复与实测结果

本轮还为已核对的游戏 EXE 和三份 Streamline 模块组合启用了 NR 绑定保护，处理首次开启 NR 后游戏崩溃的情况。同时修正共用的 Streamline 代理命令列表检查：保护逻辑现在对准实际的原生命令列表，避免保护开启后一直停在等待状态。其他游戏版本仍按各自的身份和适配事实处理。

| 检查 | 本轮结果 |
|---|---|
| FG 开启、NR 关闭，游戏在前台且面板打开 | 约 3.064 秒内，370 次成功画面提交、370 次面板绘制、370 次 GPU 完成；零新增跳过、拒绝或错误 |
| 实际可见效果 | 测试者确认「面板稳定，已经不闪了」 |
| 另一次 FG 关闭的 NR 检查 | 13,477 次执行全部完成并恢复绑定，关闭后执行计数停止增长 |
| 开关操作 | 测试者随后反馈当前切换效果均正常 |

实测环境为 RTX 5090、驱动 617.14。这些结果确认了当前场景的面板修复及上述 NR 执行行为；其他游戏、长时间稳定性、NR 与 FG 同开的画质和性能仍待验证。晚加载的未知间接调用仍采用已有的有限假设，完整绑定覆盖尚未证实。

## 本次新增：游戏库避免选错程序

- 游戏本体优先于崩溃报告器、启动辅助程序，即使它们与 DLSS 文件位于同一目录。
- 直接选到辅助 EXE 时，优先提示附近的游戏本体；检查会明确显示「不是游戏本体」，并拒绝为其生成、安装或更新插件。
- 旧版已经装错的条目仍可通过身份核验后卸载，再添加正确的游戏 EXE。

## 此前版本的累计功能：本版全部保留

以下功能已在之前的预览版中交付，均随 Preview 12 一并提供。

**游戏内控制与输入**

- NR 每次启动默认关闭；面板提供 Tone、Structure、Style、Skin 与 AutoMask、输入曝光、对比分屏和只计算模式，并显示参数读回和跳帧原因。
- 输入曝光优先使用游戏提供的可信曝光值，缺失或不可信时回退到釉光测光；手动 EV 仍可调节。
- 已识别的 310.9.16.0 模型可选「自动 / 网络 1 / 网络 2」；对比分屏可调整分界位置。外推可放大一次 NR 的改变量，也会放大过冲、细噪声等问题。
- 面板快捷键全局可改，默认 Insert，可使用 Ctrl、Shift、Alt 组合；桌面程序、游戏面板和 Steam 启动器共用设置。
- 对只通过原始输入读取鼠标、不给窗口发送常规按键消息的游戏，增加真实按键状态读取；面板绘制失败后可再次按快捷键重建。

**桌面程序、模型管理与更新**

- 游戏库支持添加、检查、生成适配包、安装、更新、重新适配和卸载，展示 DLSS 路线、文件身份、保护风险和故障原因。
- 模型可以直接重新导入切换；替换前校验并保存原文件，安装过的游戏保留自己的副本，游戏库会提示哪些游戏需要更新插件。
- 文件哈希按文件身份缓存，减少刷新游戏库时重复读取同一份大模型；安装、更新等实际操作仍重新核验。
- Setup 支持原目录升级并保留模型与设置；便携 ZIP 提供完整程序和应用本地微软运行库。
- 安装版支持程序内更新。更新清单带 ECDSA 签名，下载后核验文件大小和 SHA-256；便携版提供更新提示与下载入口。

**游戏识别、适配与故障说明**

- 游戏启动及开启 NR 的常规可用空间要求降为 256 MiB，安装插件预留 1 GiB；研究采集和导出保留各自的容量规则。
- 已审阅游戏的其他构建可使用自己的适配标识并沿用适用的游戏设置，改善游戏补丁或商店版本变化后的安装、重新适配问题；安装时仍执行身份核验。
- 插件仅在安装时选定的游戏 EXE 中启动，目录里的其他启动器保持静默转发。
- 启动或 NR 创建失败时给出更明确的中文处理提示，保留原始错误和 NGX 返回码；找不到 DLSS 时会说明有限搜索范围内是否在其他位置找到文件。
- 兼容的已保存采集内容仍可在独立浏览器中查看。

## 如何升级

1. 正常退出游戏。安装版可在釉光内接受新版更新，或退出釉光后运行 Preview 12 Setup，选择原来的安装目录；便携版完整解压新 ZIP。
2. 打开游戏库，对需要新版文件的游戏点一次 **「更新插件」**。只升级桌面程序，游戏里的插件仍是旧版。
3. 正常重新启动游戏，进入场景后按面板快捷键打开面板。游戏本身更新后若显示「需适配」，先按界面提示「重新适配」。

晚加载游戏继续使用游戏库显示的 Steam 启动选项。模型仍由用户自行提供，升级保留已有模型和设置；安装包及便携包均不包含或下载 NVIDIA 模型。

## 验证与适用范围

共享修复已通过 102 项非 GPU 原生回归、89 项 Python 检查（其中 1 项跳过）以及 780 项真实 NVIDIA GPU 见证器检查；GPU 调试层零错误，包含布局初始化后 20 帧连续像素检查、原提交边界以及独立绑定钩子共存检查。 发布构建另通过真实 NR 合成夹具的默认、绑定保护、深度模板和超分四种变体；这些夹具检查与上文游戏内实测分别记录。

釉光仍是实验性的第三方 NR 工具，适用于使用 DX12 和 DLSS 的游戏，NR 默认关闭。当前只在 RTX 50 系上测试过；具体游戏情况见 [兼容性说明](https://github.com/HANsoA-KevinO/overglaze/blob/v0.2.0-preview.12/SUPPORTED_GAMES.md)。不等同于官方 NR 集成，也不绕过游戏保护。

本次继续作为预发布版提供。Setup 本身尚未进行 Authenticode 签名；发行附件包括安装包、便携 ZIP、SHA-256 校验文件、构建回执，以及带签名的程序内更新清单。
